Use the read-only beneficiary network catalog to verify your API key, environment, and response handling without creating a resource.

## Before you begin

You need an approved merchant account, the `api_access` feature, and a test API key with `api:read` or `api:write`.

<Info>
  The full API key secret is displayed once. Store it in your secret manager and never commit it.
</Info>

## Make a sandbox request

```bash
export TRANSIKA_API_KEY="txk_test_REPLACE_ME"

curl --request GET \
  --url "https://sbx-institutional.tran-sika.com/sandbox/v1/beneficiaries/networks?kind=momo" \
  --header "Authorization: Bearer ${TRANSIKA_API_KEY}" \
  --header "Accept: application/json"
```

## Read the response

```json
{
  "status": "success",
  "message": "success",
  "data": {
    "networks": [
      { "code": "MTNGH", "label": "MTN Mobile Money", "kind": "momo" }
    ]
  }
}
```

The exact fields inside `data` depend on the endpoint.
